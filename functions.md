# Вывод на экран

`write_string(string)` - выводит строку на экран (до нулевого байта).

`put_char(char)` - выводит символ на экран. Поддерживает автоперенос строк (автоскролл включается флагом `automs`).

`wsf(string, ...)` - аналог printf, но с другим использованием:
Первый аргумент - форматная строка. Поддерживает эти символы: **s, d, x, b, c**, а также пробел и перенос строки как литералы. Каждый символ означает **1** аргумент (кроме пробела/переноса строки - они ничего не читают, просто печатаются как есть).
- **s**: строка в двойных кавычках (`char*`).
- **d**: целое число, печатается в десятичном виде.
- **x**: целое число, печатается в HEX.
- **b**: целое число, печатается побитово (32 бита).
- **c**: символ в одинарных кавычках, либо переменная типа `char`/`int`.

Символы, не входящие в `sdxbc` и не являющиеся пробелом/переносом строки, молча игнорируются и не читают аргумент. Каждый символ форматной строки обязан соответствовать ровно одному переданному аргументу нужного типа - несовпадение количества/порядка сдвигает все последующие чтения и портит вывод.

`clear_screen()` - очищает экран текущим цветом (`VGA_COLOR`), сбрасывает курсор в начало.

`move_screen()` - прокручивает содержимое экрана на одну строку вверх, последнюю строку очищает. Используется автоматически при переполнении экрана, если включён автоскролл.

`move_cursor()` - обновляет позицию аппаратного курсора VGA согласно текущему значению `cursor`. Вызывается автоматически внутри `put_char`/`del_symbol`/`clear_screen`.

`del_symbol()` - стирает последний выведенный на экран символ и сдвигает курсор на одну позицию назад.

`set_char(x, y, char)` - выводит символ в конкретную позицию экрана (столбец x, строка y) без изменения текущего курсора.

`get_char(x, y)` - читает символ, находящийся в конкретной позиции экрана.

`put_char_color(char, color)` - выводит символ заданным цветом, не меняя `VGA_COLOR` для последующего вывода.

# Клавиатура

`get_string(buffer, char, int, flags)` - универсальная функция для ввода с клавиатуры:
- Первый аргумент - буфер, в который будет записан ввод.
- Второй аргумент - символ-терминатор. Если терминатор отключён (см. третий флаг), рекомендуется писать `NO_TERM`.
- Третий аргумент - максимальный размер строки. Он ДОЛЖЕН быть меньше или равен размеру буфера минус 1 (под завершающий нулевой байт).
- Четвёртый аргумент - флаги. Запись выглядит как `0b000`, где некоторые из трёх нулей заменены единицами:
  - Первый флаг (`0b001`) отвечает за печать символов. Если флаг включён, введённые символы отображаются на экране по мере ввода. Если выключен - ввод работает, но ничего не появляется на экране.
  - Второй флаг (`0b010`) отвечает за работу функциональных клавиш во время ввода. Если включён, при вводе будут работать F1 (ввод символа по коду) и F5 (перезагрузка).
  - Третий флаг (`0b100`) отвечает за работу терминатора. Если включён, терминатор (второй аргумент) игнорируется, и ввод продолжается, пока пользователь не введёт ровно указанное в третьем аргументе количество символов.

Функция поддерживает Backspace во время ввода.

`read_key(bool)` - читает одну клавишу с клавиатуры. Блокирующий вызов. Аргумент определяет работу функциональных клавиш - если в аргументе любое число, кроме 0, будут работать клавиши F1 и F5.

`choice(string)` - блокирующий выбор из нескольких символов. В строке находятся все доступные для нажатия клавиши; как только одна из них нажата, функция возвращает её (саму нажатую клавишу, а не её номер в строке).

`wait_keypress()` - ожидание нажатия любой клавиши. Разрешает использование функциональных клавиш (F1, F5).

# Строки

`strcmp(str1, str2)` - сравнивает две строки. Возвращает 0, если строки идентичны.

`strlen(str)` / `length(str)` - возвращает длину строки без завершающего нулевого байта.

`memcpy(dest, src, n)` - копирует n байт из src в dest. Возвращает dest.

`memset(dest, val, n)` - заполняет n байт по адресу dest значением val. Возвращает dest.

`stradd(buffer, str1, str2)` - записывает в buffer конкатенацию str1 и str2. buffer должен иметь достаточно места и не быть тем же указателем, что str1 или str2.

`cut(str, needle)` - удаляет из str первое вхождение needle, сдвигая остаток строки влево.

`int_to_str(n, buf, size)` - преобразует число n в десятичную строку. Возвращает buf.

`hex_to_str(n, buf, size)` - преобразует число n в строку вида "0A", "FF" и т.д. Возвращает buf.

`str_to_int(str)` - преобразует десятичную строку в число. Не понимает HEX, останавливается на первом нецифровом символе (кроме ведущего минуса).

`str_to_hex(char)` - преобразует один символ 0123456789abcdef в число 0-15.

`hex_to_char(int)` - обратная операция: число 0-15 в hex-символ.

# Порты ввода-вывода

`outb(port, value)` / `inb(port)` - запись/чтение одного байта в/из порта.

`outw(port, value)` / `inw(port)` - запись/чтение слова (2 байта).

`outl(port, value)` / `inl(port)` - запись/чтение двойного слова (4 байта).

`pci_read(bus, slot, func, offset)` / `pci_write(bus, slot, func, offset, value)` - чтение/запись конфигурационного пространства PCI-устройства через порты 0xCF8/0xCFC.

`mmio_read32(addr)` / `mmio_write32(addr, val)` - чтение/запись 32-битного значения по физическому адресу памяти.

`scan_pci()` - перебирает все bus/slot/func и печатает информацию о каждом найденном PCI-устройстве. Блокируется после каждого найденного устройства до нажатия клавиши.

# Время

`rtc_wait()` - ждёт, пока CMOS RTC не закончит внутреннее обновление, перед тем как читать время/дату.

`rtc_read(reg)` - читает один регистр CMOS RTC (0x00 - секунды, 0x02 - минуты, 0x04 - часы, 0x07 - день, 0x08 - месяц, 0x09 - год). Сама определяет формат данных (BCD или бинарный) и всегда возвращает обычное число.

# Прерывания

`idt_flush(ptr)` - загружает таблицу прерываний через инструкцию lidt.

`isr_handler(frame)` - центральный обработчик всех исключений процессора (0-31). Печатает панику через Cpanic с именем произошедшего исключения.

`Cpanic(string)` - выводит красный экран паники с переданным сообщением, ждёт нажатия клавиши, затем перезагружает систему. Не возвращает управление.

# Прочее

`delay(ms)` - блокирующая задержка на заданное количество миллисекунд через PIT.

`split_command(input, cmd, args)` - разбивает введённую строку по первому пробелу на команду и аргументы. Если пробела нет, args устанавливается в 0 (NULL).
