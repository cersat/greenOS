# GreenOS - **операционная система** для запуска на реальном ПК

## Что внутри
* ``` kernel.c ``` - Основное ядро системы. Запускается из ассемблерного загрузчика
* ``` boot.asm ``` - Ассемблерный загрузчик. Запускает основное ядро, имеет встроенное сообщение об ошибке чтения диска
* ``` diskcall.asm ``` - Вызов трамплина для доступа к диску через BIOS INT13h из 32-битного кода
* ``` tramp.asm ``` - Трамплин между protected mode и real mode для диска и восстановления IDT
* ``` isr.s ``` - Обработчики исключений (ISR 0-31) и загрузка IDT
* ``` \lib ``` - Папка с библиотеками (видео, клавиатура, диск, файловая система, строки)
* ``` linker.ld ``` - Конфигурация для линковщика
* ``` run.sh ``` - Скрипт для сборки и запуска в Qemu
* ``` create.sh ``` - Скрипт для сборки и загрузки на флешку
* ``` functions.md ``` - Документация по функциям

## Как запустить:

Требуется:

### 1. Qemu

* Сам Qemu
* i686-elf **Компилятор**, **линковщик**, **objcopy** (Обычно скачиваются вместе)
* Nasm

#### Порядок действий:  

* Перед первым запуском надо создать пустой образ, делается командой: ``` dd if=/dev/zero of=disk.img bs=1M count=16 status=progress ```, также вы можете зайти во вкладку релизов на GitHub и скачать образ оттуда
* Запустить скрипт **run.sh**

### 2. Реальный ПК

* i686-elf **Компилятор**, **линковщик**, **objcopy** (Обычно скачиваются вместе)
* Nasm
* Флешка
* Rufus

#### Внимание: скрипт для загрузки на флешку имеет **batch** формат и требует запуска на windows

#### Порядок действий: 

##### Для загрузки на флешку:
* Запустить скрипт **create.sh**
* Подключить к компьютеру флешку
* Дождаться появления окна от UAC (окно может появиться в свёрнутом виде)
* Разрешить Rufus изменения на этом устройстве
* Выбрать флешку 
* В папке с исходниками появится файл **os-image.bin**. Надо выбрать его в окне выбора файла
* Нажать кнопку **Старт** 
* Перезагрузиться

## Файловая система

Собственная файловая система (MAT - Mark Allocation Table) с bitmap-аллокатором секторов.

* Список команд для работы с файлами: ``` touch ```, ``` select ```, ``` del ```, ``` dir ```, ``` write ```, ``` strwrite ```, ``` read ```
* Перед записью/чтением файла нужно выбрать его командой ``` select <путь> ```
* Диск форматируется автоматически при первом запуске (запрашивается имя диска)

## Список команд шелла

``` color ```, ``` cls ```, ``` echo ```, ``` delay ```, ``` run ```, ``` dumb ```, ``` info ```, ``` strwrite ```, ``` write ```, ``` read ```, ``` select ```, ``` tab ```, ``` charmap ```, ``` divnull ```, ``` scan_pci ```, ``` panic ```, ``` reboot ```, ``` touch ```, ``` del ```, ``` dir ```, ``` in ```, ``` out ```, ``` time ```, ``` date ```, ``` utc ```
