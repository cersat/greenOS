# Коды ошибок команд

Каждая команда возвращает `cmd_ret` - структуру с полем `errorcode` и текстовым сообщением `error`. Если `errorcode` равен 0, ошибки нет и ничего дополнительно не печатается. Если `errorcode` не равен 0, диспетчер (`execute_command`) печатает `[код]сообщение` через `wsf`.

| Код | Значение | Возникает в |
|-----|----------|-------------|
| 1 | Некорректное значение аргумента (например, `delay` вне допустимого диапазона) | `delay`, `color` |
| 2 | Файл не выбран (`select` не вызывался, либо `read_select == 0`) | `run`, `dumb`, `strwrite`, `write`, `read`, `del` |
| 3 | Отсутствует требуемый аргумент | `color` |
| 4 | Файл не найден (путь, переданный в `select`, отсутствует на диске) | `select` |

Код `3` зарезервирован под ошибку переполнения диска, но пока ни одна команда его не возвращает - `alloc_sector`/`setFile` сейчас молча не выполняют операцию, если места не осталось, вместо явного возврата кода ошибки наружу.

## Как это устроено в коде

Ошибка выставляется прямо внутри тела команды, без отдельной функции-конструктора:

```c
cmd_ret ret;
ret.errorcode = 0;
if (<условие ошибки>) {
    ret.errorcode = N;
    strcat(ret.error, "текст сообщения");
    return ret;
}
```

## Добавление нового кода ошибки

1. Выбрать свободный номер, не совпадающий с уже занятыми выше.
2. Внутри нужной команды выставить `ret.errorcode = N;` и `strcat(ret.error, "...");` перед `return ret;`.
3. Добавить строку в таблицу выше.

Один и тот же номер не должен означать разные вещи в разных командах - если ошибка семантически новая, используйте новый номер, а не переиспользуйте существующий с другим смыслом.
